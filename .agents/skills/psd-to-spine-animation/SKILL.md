# 从 PSD 制作 Spine 动画

按项目确认目标动作、播放方式、Spine 编辑器及运行时版本、画布、原点和交付格式。沿用用户已给出的数值和限制。用户未指定常规参数时，选择与目标平台和动作相称的参数并记录假设。动作的时长、制作采样率、导出预览帧率和 Spine 关键帧数量分别处理。

## 1. 审查素材并重建静态图

- 保留原 PSD，在工作目录建拆件。递归检查组、智能对象及内嵌 PSB，记录对象变换、图层顺序、蒙版、剪贴蒙版、透明度、混合模式、效果、画布坐标和色彩配置。已拆好的素材优先复用。外链智能对象缺失时记录哪一块缺失。
- 标记运动部位、固定部位、换件、前后遮挡和可能露出的缺画区域。根据动作幅度补齐关节背面或翻转可见区域，用原图颜色和边缘作基准。源素材只有一张合成图时，先估算哪些区域可拆、哪些需要重绘。
- 导出带透明通道的单图，保留裁切尺寸、相对画布的偏移和统一比例。先用这些图重建静态姿势，检查颜色、接缝、遮挡与截图参考一致。PSD 合成效果如无法由目标运行时复现，按需要烘焙到相关部件。
- 收到参考 `.skel` 时，先读版本，并用对应运行时核对骨骼、插槽、附件、网格、约束、采样姿势和关键帧。图集 PNG 缺失时，可以分析 `.atlas` 元数据和骨架行为，完整像素比对需图集原图。Spine 3.8 可用随附脚本：

  ```bash
  node scripts/inspect-spine38.cjs /path/to/official-spine-webgl.js /path/to/file.skel /path/to/file.atlas
  ```

## 2. 按部件功能选择结构

| 素材或动作 | 合适的结构与检查 |
| --- | --- |
| 人物、怪物、宠物 | 把关节中心放在正确位置。硬质配件跟随骨骼，肩肘、膝盖、头发、布片或软组织用局部网格和权重。脚步、手持物、眼睛、嘴型和遮挡按实际动作选择固定、换件或约束 |
| 道具、机械、载具 | 硬质部件使用 Region 和旋转、平移骨骼，同轴部件共用枢轴。斜视旋转保留体积，原本贴合的部位共用控制骨或投影；大角度露出缺画时补视角图 |
| UI、奖励标识、界面物件 | 将主图、文字、数字、边框和光效分槽。根据需求设置显示、强调、停留和退出。保住信息读序与可读性；需要换文案时保持文字可替换 |
| 发光、烟雾、技能、元素特效 | 用独立槽控制运动、颜色、透明度和混合模式。用少量附件换图处理复杂形变，用 Region、网格或裁剪处理能由几何表达的效果。检查亮度、叠加和性能 |
| 场景、植被、环境物件 | 固定远景和锚点，给可摆部件做局部网格或骨链。用不同相位避免整组同拍。需要交互定位时单独保留对象根节点或定位槽 |

先用 Region 和骨骼完成主体，确有弯曲、补偿透视或贴合接缝时再加网格。网格把顶点放在轮廓、关节和曲率变化处，权重过渡需要在极限姿势和中间姿势都成立。附件换图用于表情、视角、遮挡和复杂特效。换图前后校准原点、长度和轮廓。回转、移轴、点亮及开关图层都应落在有明确用途的骨骼或插槽上。

## 3. 先搭动作，再加层次

1. 按用途标出关键姿势和节奏。循环明确首尾和运动相位，单次动作明确准备、命中或强调、收尾，状态切换明确进入和退出条件。使用稳定的根骨区分原地播放与带位移播放。
2. 先用骨骼动画检查剪影、重心、可见方向和接触点。再加入次级运动、速度模糊、扫光、碎片和层次遮挡。将重要动作的幅度、色彩和节拍留给视觉重点。
3. 首尾要与静态图一致时，先让几何、附件、颜色、绘制顺序及发光自然归位。要求逐像素一致且拆件重建有细微差异时，可单独配置静态参考附件，在同姿势下与活动层交接，并记录对应图集页。
4. 修改现有版本时，以用户最近确认的版本为基线。保留已有骨骼结构和附件名字，除非改动本身需要变更。将新动作作为可识别的动画或文件交付，并说明替换关系。

## 4. 精简、验证与交付

先锁定动作表现，再减少多余数据。用 Region 替换无形变的矩形网格，用骨骼替换纯旋转或平移的逐帧变形。删除常值或重复键，按可接受的位移、角度、透明度和画面误差简化插值；保留接触、切图、事件、首显和首尾。对长角度旋转检查运行时是否走最短弧。

在目标版本运行时或编辑器验证绑定和导入，区分实际做过的检查。以相同画布、时间点和渲染配置检查优化前后，抽查峰值、换层、快速运动和子帧。循环用实际循环播放检查相位与接点，单次检查末帧和后续切换，要求像素一致时直接比较实际渲染和原图。核对 atlas 的所有页、裁切和旋转、采样、透明混合方式及链接路径。

按照请求交付 Spine 工程（有相应编辑器并已生成时）或可编辑 JSON 与单图，另提供运行时数据、配套图集及预览。记录版本、导入入口、动画名、时长、循环属性和资源依赖。按用户授权目的地提交并回读文件。
